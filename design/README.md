# Design canvas

Source artboards for the yt·transcribe redesign — an editorial, reading-first
direction (warm off-white, Newsreader + IBM Plex, one terracotta accent).

- `*.dc.html` — one artboard each (Design Components format)
- `canvas.json` — canvas layout, pages, launch view
- `yt-transcribe-redesign.html` — the seeded, publishable bundle (gitignored;
  regenerate with the seed helper from the `design` skill)

The `Redesign` page holds the deliverable; `Other directions` keeps the two
low-fi alternates that weren't chosen.
